# cert-manager

Automates TLS certificate issuance and renewal across the fleet using Let's Encrypt with DNS-01 validation via AWS Route53.

**Documentation:** Open [component-viewer.html](.skills/fleet-common/assets/component-viewer.html) and load `components/cert-manager-configuration/cert-manager.json`.

**Upstream:** [Red Hat cert-manager Operator for OpenShift](https://docs.openshift.com/container-platform/latest/security/cert_manager_operator/index.html)
